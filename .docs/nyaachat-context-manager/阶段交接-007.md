| 闸门 | 说明 |
|---|---|
| 开关默认关闭 | 未登录 / 首次登录时，账号界面「持久化记忆」开关应为**关闭** |

| 清空全部记忆 | 「清空我的全部记忆」→ `DELETE /memory/all` |
