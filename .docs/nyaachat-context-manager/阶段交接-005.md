|---|---|

| 锚点缓存失效 | `SESSION_PROTOCOL_ANCHOR` 扩展会使全量前缀缓存一次性失效，commit message 中已注明预期行为 |
| `pendingSendRef` 时序 | 提炼成功后在 `setMessages` 之前更新 `pendingSendRef.baseMessages`，确保 `sendChat` 使用已标记的快照。`setMessages` 异步更新但 `sendChat` 不依赖 React state 的 message ref（使用参数传入的 `baseMessages`），时序安全 |
| `messagesRef.current` 与 `messages` state 一致性 | `messagesRef` 由 `useEffect` 同步，标记后可能存在一帧的不一致。影响面评估：仅 `handleRegenerate` 和 `sendUserMessage` 使用 `messagesRef.current`，均不涉及记忆边界逻辑 |
| 知识库服务端无需改动 | P5 全部改动在主仓，`nyaachat-knowledge` 零改动 |
