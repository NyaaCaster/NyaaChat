- shared-server：DB 迁移 + 扩容/消耗端点 + profileOf 字段
- 前端数据层：`AccountProfile.comfyuiPackRemaining` + `expandComfyuiPack`/`consumeComfyuiPack` API
- 共享账号面板：NyaaComfyUI图包行（剩余次数 + 扩容按钮）
- 节点设置界面：图包剩余 + 扩容 + 启用开关登录 gate（仅 `comfyui-fixed`）
- 对话生图链路：登录 gate + 剩余预检 + 成功后 −1 + 耗尽弹窗（仅 `comfyui-fixed`）
- 打开面板时自动 `fetchProfile` 刷新最新剩余次数
