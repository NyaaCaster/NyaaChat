### F1 — **blocker**｜`zod.mjs` 的 MIME 使整条脚本链失效（P3 运行期 100% 失败）
- **证据**
  - `curl -I http://127.0.0.1:4095/vendor/script-host/zod.mjs` → `HTTP/1.1 200`、`Content-Type: application/octet-stream`、`X-Content-Type-Options: nosniff`
  - 容器：`grep mjs /etc/nginx/mime.types` → 无命中（只有 `application/javascript js;`）
  - 同一浏览器内：`import('/vendor/script-host/zod.mjs')` → `Failed to fetch dynamically imported module`；`import('/vendor/script-host/zod/zod.esm.js')` → **ok keys=260**（即被包装的官方产物本身没问题）；`import('/vendor/script-host/yaml.min.js')` → ok
