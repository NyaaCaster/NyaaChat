**该版实现与初版的一个语义差别（值得记入契约说明）**：初版 `QuoteTtsButton` 会把 `text`（被朗读的原文）
**渲染在按钮内部**；现版只渲染图标，原文完全由**宿主**输出。因此"原文出现次数"= **1**（而不是"正文 1 次 + 按钮 1 次"）。
这是**更好**的形态（正文只渲染一份、按钮只承担播放），但它意味着：

### 6.1 可复用手法（captain 提出，本次独立复算通过）：**用"新旧文案字面量在/不在"判定产物来源**

判断"线上镜像是否含某次修复"，比 mtime / "我构建过没有" / 哈希变化都更直接的办法是：
