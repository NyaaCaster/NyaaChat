## 布局与行为

1. 沿用当前扩展窗口的左右栏、详情头部、总开关、蓝色选中行及运行日志；手机提供返回列表入口。
2. 说明首先声明已核验的 Qwen3.6 / Qwen3.5 模板约束及跨供应商适用范围，另列具体核验型号。
3. AnswererFlagalac / RuleBreaker 提示采用现有琥珀色警告块，RosettaStone 支持说明保留在同一块中。
4. 按供应商分组逐模型选择，默认插件停用且没有选中项。总开关关闭时仍可预配置。停用供应商和不适用接口显示原因。
5. 不可用配置单独展示，保留供应商和模型的名称、不可用原因及“移除配置”操作。
6. thinking、截断恢复及重新生成的边界仅以文字说明，不增加相关开关、预算设置或恢复按钮。

## 预览范围与检查

HTML 自包含，无外部字体、依赖或 API 请求；开关、搜索、移除配置及场景切换仅修改页面内存，刷新还原。其他插件仅用于还原列表外观，关闭按钮不关闭页面。正式设置的持久化、日志和模型能力不在本稿中实现。
