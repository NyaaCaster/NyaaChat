## 运行路径

```
用户点「生图」(comfyui-fixed)
  AGENT_ENABLE=true:
    buildFixedComfyPromptRequest → {system, user}
    → fetchT2iAgentPrompt → POST /api/ext-host/t2i-agent/chat
    → nginx → ext-host:3099 → deepseek API（部署方 key）
    → 英文提示词 → generateComfyImage → 出图 → 扣费

  AGENT_ENABLE=false:
    buildFixedComfyPromptRequest → {system, user}
    → fetchChatCompletion（用户对话 LLM）
    → 英文提示词 → generateComfyImage → 出图 → 扣费

  LLM 失败:
    → buildImagePrompt（字符串拼接 fallback）
```
