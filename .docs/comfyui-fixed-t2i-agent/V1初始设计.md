# 设计目的
为 COMFYUI_FIXED (NyaaComfyUI) 画图提示词生成路径设计一套独立的生成路径：
-  NyaaComfyUI 生成节点要花费用户的 NyaaComfyUI图包 额度，是付费项目，需要做得比第三方API或用户自定义comfyui路径生图效果更佳才能吸引用户付费。
-  允许 NyaaComfyUI 生成节不再使用用户的对话模型api来成生提示词，在 NyaaChat\.env 中我加入了 COMFYUI_FIXED_T2I_AGENT_ENABLE 条目来决定是否要启用 NyaaComfyUI 独立agent 来生成提示提示词
   -  false：不启用，这个状态下 COMFYUI_FIXED (NyaaComfyUI) 原本的 COMFYUI_CUSTOM（自定义comfyui）路径提示词生成方案
   -  ture：启用，这个状态下，使用 新得 NyaaComfyUI 独立agent 来生成提示词，并且由部署方（现在是我——Nyaa）来承担 NyaaComfyUI 独立agent 的API费用（NyaaChat\.env 中我加入了 COMFYUI_FIXED_T2I_AGENT_API_ 三项API配置）。

## NyaaComfyUI 独立agent 
### 画图提示词生成逻辑
#### 当前问题
- 固定提示词 system prompt 过于简陋，像是机械化生成，缺少画面感描述。
- 组装内容 user message 只是翻译，并且存在截断，内容容易割裂。
#### 解决方案（V1版本）
- 内容要素：参考我最新给出的一版 NyaaChat\public\comfyui\TestPrompt.md ，对这段样本进行分析，至少需要以下维度（最好给出更多适合的维度）：
  - 对角色的描述需要拆分出：年龄、人种、身份、衣着、性格、状态，这些构成角色塑造的关键。
  - 对角色在画面中的形象要进行界定：动作、视线、神态、行为阶段，这是构成一个角色行为切片分镜的关键。
  - 场景、情景的描写：场景元素、画面主题元素、画面气氛元素、画面布局、角色相关物件、显性和暗示的元素，这是一个构图功底的关键。
  - 气氛表达描写：画面传达的情绪、故事、真实性、美学、主题色调，这是构图美术优劣的关键。
  - 着眼点选择：要判定用户的视角和用户与角色的互动程度，决定现在时画角色的单人还是角色与用户的同框行为，甚至考虑是该画单角色还是群像（主次、背景角色等）
  - 视觉术语：摄影风格、镜头类型、拍摄角度、取景范围、质感、光照、光圈、进深，这是所有comfyui模型构建画面效果的通用语言。
  - 约束条件：必须保持的内容、必须避免的内容（在自然语言生图模型中取代了负面提示词）
  - 合适的段落分段：注意 TestPrompt.md 中的 \n 换行，合适内容在一个段落中，有助于自然语言画图模型对一个需求要要素的理解，合理组装段落换行后的生图效果远高于从头到尾全塞进一句话。
- 内容要素结构化样例：这里可以再参考一个逻辑结构化拆分后的样例 NyaaChat\.ref\一个结构化的画图提示词样例.md ，不要照抄，但这样便于理解如何规划需要生成提示词的要素。
  - TestPrompt.md 进行结构化拆分后是这样的：NyaaChat\.ref\TestPrompt的结构化拆分.json ，请用于参考。
  - 注意：结构化拆分法，只是用于语义分析和构建提示词的组装要素，实际最后生成的提示词必须是分段落的自然语言，这不是简单的拼接，后文我会说到。
- 最终提示词的生成：对话历史记录（哪怕只是前4轮）组装内容 user message 目前是纯翻译，这样也是不对的，和上面的构图结构化要素拆分是一样的，本身就需要从这4轮对话中把角色和用户的这些信息都结构化拆除出来，而所有这些结构化元素，不是简单的拼接和翻译，是作为生成画图提示词的提示词本身，让LLM去分段落生成自然语言提示词，只不过要求是生成英文的提示词而已。
- 字数问题：看下 TestPrompt.md 最终字数范围是多少，生成的提示词字数以 TestPrompt.md 的字数为参考。
  - 注意这里不是截断，而是想 `RosettaStone` 系统中的 `字数控制` 实现方式一样，本身把字数要求作为一个提示词信息插入给LLM（语言约束也是一样，英文要求）。

# 结论
现在你是否理解了我为甚把这个LLM生成提示词的机制称为一个agent了吧？这是一个完整的条件话LLM生成逻辑，而不是机械的筛检、组装、翻译。
实现的时候需要以agent设计的角度出发，去有效的完成这个设计，比起实现代码模块，这是才你的长项。
- 一个关键点：既然生成画图提示词的LLM"对话"本身不积累、占用上下文，这个LLM生成过程就有足够的上下文区间去做优质的完成这个分析、设计、生成过程，不仅高效，而且便宜。
