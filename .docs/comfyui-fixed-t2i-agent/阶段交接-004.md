### System Prompt 调优

P2 自测发现已知角色（木之本樱）细节漂移问题——LLM 预训练冲突导致"棕色短发+绿色眼睛"被改写。P4 在 system prompt 中增加：

> Crucially, preserve all specific identifying details from the input exactly as described — hair color, eye color, distinctive marks, scars, accessories, and clothing colors must match the character description faithfully. Do not substitute details from your own knowledge of the character.
