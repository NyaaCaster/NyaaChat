## System Prompt 架构

**Layer 1** — 角色定义 + RosettaStone 分离声明  
**Layer 2** — 7 维度内部思考框架：
1. Subject Identity（年龄/人种/身份/衣着/性格/状态）
2. Subject Portrait Slice（动作/视线/表情/行为阶段）
3. Scene Composition（环境/主题/氛围/布局/物件/显隐元素）
4. Atmosphere & Mood（情绪/故事/真实感/美学/色调）
5. Viewpoint（视角/亲密感/单人vs同框vs群像）
6. Visual Vocabulary（摄影风格/镜头/角度/取景/质感/光照/景深）
7. Constraints（must-keep / must-avoid）

**Layer 3** — 输出格式要求（分段自然英文 / 300-400 词 / 5-7 段 / 纯英文 / 无标记）
